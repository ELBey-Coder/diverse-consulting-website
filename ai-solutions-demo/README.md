# Diverse Consulting AI Solutions Demo

This folder contains the private review copy of the interactive AI Solutions demo.

## Review

Open `index.html` with a local web server to review the full interactive experience. The page uses the official Diverse Consulting logo in the header and footer.

The form is intentionally a preview only and does not transmit customer information. It can be connected to `/api/leads`, a CRM, or a booking calendar after approval.

The existing website homepage and the `main` branch are unchanged.
