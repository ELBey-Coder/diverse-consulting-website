Diverse Consulting working multi-page site

How to open:
1. Unzip this folder.
2. Open this folder in VS Code.
3. Right-click index.html.
4. Click "Open with Live Server".

Fixed:
- Every header tab links to a real separate page.
- Every page has the same visual design style as the home page.
- The uploaded logo is embedded in the top-left header on every page.
- The site does not depend on an external CSS file, so it will not load as plain text from a broken CSS path.
- Open logo-proof.html to confirm the logo and page links.
