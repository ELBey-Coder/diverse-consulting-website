# Diverse Consulting Next.js Original Design Upgrade

Preserves original design, logo, favicon, theme, content, chatbot concept, and assets while improving contrast and wrapping the site in Next.js.

Run:

```cmd
cd nextsite
npm install
npm run dev
```

Netlify: build `npm run build`, publish `out`.

## AI Solutions Demo

The interactive AI automation demo is included at `/ai-solutions/`. Its static
files are stored in `public/ai-solutions/`, and the Next.js development route is
defined in `app/ai-solutions/page.tsx`.
